# Code of Conduct

## Our standard

Pinky is an inclusive project. Contributors must be respectful and welcoming
regardless of gender identity, sexual orientation, race, disability, religion,
age, or background.

Unacceptable behavior includes harassment, discrimination, threats, hate
speech, sexual harassment, deliberate intimidation, and sharing private
information without permission.

## Responsibilities and reporting

Project maintainers may remove or reject content that violates this standard.
Report concerns privately to the repository maintainers through GitHub rather
than posting sensitive details publicly.

We will review reports fairly, protect confidentiality where possible, and
respond with appropriate action.
