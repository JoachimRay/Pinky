# Changelog

All notable changes to Pinky are documented here.

## [Unreleased]

### Added

- LGBTQ+ profile browsing with Pass and Violet actions.
- Simulated mutual matching and local chat sessions.
- Conversation opening and follow-up suggestions.
- Optional Ollama-powered suggestions and message rewriting.
- Optional OpenRouter-powered profile openers with curated fallbacks.
- AsyncStorage persistence for the local demo session.
- Architecture, setup, AI, testing, and troubleshooting documentation.

### Known limitations

- Profiles, matching, and messages are local demo data.
- There is no production authentication, cloud database, or real-time WebSocket server.
- AI features require a local Ollama setup or OpenRouter configuration.
- Production moderation, reporting, blocking, and notifications are not implemented.

### Planned

- Production backend, authentication, and persistent cloud data.
- Real-time messaging and notifications.
- Production AI hosting, monitoring, privacy controls, and moderation workflows.
- Expanded automated end-to-end testing.

## [0.1.0] - 2026-10-23

- Initial Pinky MVP release.
